# 画面素材来源

## 1. `scroll.webp`（全站背景手卷）

克利夫兰艺术博物馆藏《溪山无尽图》（Streams and Mountains without End），
中国，北宋末至金（约 1100–1150），绢本水墨淡设色手卷。

- 馆藏编号：1953.126
- 来源：https://clevelandart.org/art/1953.126
- 授权：**CC0**
- 处理：馆方公开图 3400×525 → 6000×926，锐化、降饱和，转 WebP（464KB，原 JPEG 877KB）。

## 2. `chubo-feng.webp` / `chubo-yu.webp`（图鉴「镇馆」楚帛画）

- 《人物龙凤帛画》，战国，长沙楚墓，湖南省博物馆藏
- 《人物御龙帛画》，战国，长沙楚墓，湖南省博物馆藏

来源：Wikimedia Commons（Google Art Project 扫描）

- `Figure with Dragon and Phoenix - Google Art Project.jpg`
- `Figure Driving a Dragon - Google Art Project.jpg`

授权：**Public Domain**（战国文物，作者不详；馆方扫描为忠实复制）
处理：裁去装裱与灰边，只留绢面，高度 1200，转 WebP（212KB / 126KB）。

## 3. 纹样

所有纹样由前端引擎按参数实时生成，不依赖外部图片。
图鉴中的「拓本」是引擎输出的墨色版本：去色 + 压暗 + 正片叠底 + 纸纹 + 宣纸噪点，
并按纹样单独设定「墨性」（浓度 / 对比 / 不透明度），不是扫描件。

## 4. 正式版建议

- 背景可换为同尺寸（6000×926）的自绘或授权长卷；
- 帛画可换为博物馆官方高清图（需确认授权），或保留这两张公有领域版本。
